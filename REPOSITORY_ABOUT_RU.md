# Текст для About репозитория

## Короткое описание

Windows-приложение для поиска, фильтрации и открытия публичных proxy-конфигов в Hiddify.

## Длиннее

Anfisa VPN — локальная desktop-лаборатория для работы с публичными VLESS / VMess / Trojan / SS конфигами: с быстрым отбором, recovery-режимами и удобным открытием в Hiddify.
